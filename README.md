# Nexora Constructions - Master Architectural Website

Official website and executive management portal for Nexora Constructions.

## Features
- **Frontend**: Full luxury architecture and engineering showcase, responsive design, vanillla HTML/CSS/JS.
- **Database**: Integrated live with Supabase (Consultations and Newsletter Subscribers).
- **Authentication**: Staff and Client Portal at `/portal.html` powered by Supabase Auth (`@supabase/supabase-js`).
- **Deployment**: Configured for Vercel.
